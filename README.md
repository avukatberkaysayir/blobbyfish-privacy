# Blobby Fish — Gizlilik Politikası

Bu depo **yalnızca** gizlilik politikası sayfasını yayınlamak için var.
Google Play, gizlilik politikası için herkese açık bir URL zorunlu tutuyor;
oyunun kendi deposu özel ve GitHub Pages özel depolarda ücretli plan istiyor.

Sayfa: https://avukatberkaysayir.github.io/blobbyfish-privacy/

Kaynak dosya oyunun deposunda `docs/privacy-policy.html`. **Orası asıl kopya.**
Politika değişince buraya da kopyalanmalı, yoksa yayındaki metin eskir.
